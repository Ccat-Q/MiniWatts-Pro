# 保留完整记录样本并按会话存储

用户选择长期保留全部每 5 秒记录的样本，由用户主动清理，而不是沿用最近 60 次会话及每会话隔点抽稀的限制。继续使用单个全历史 JSON 会让启动和周期保存成本随全部历史增长，因此改为按会话保存；使用带格式版本的独立会话文件和可重建摘要索引，完整曲线按需读取。这个取舍增加了文件管理工作，但保留了 CSV 复算所需的采样点，并避免用有损曲线承担分析依据。

采样点同时保存累计计量值，以支持相同电量区间的能量、平均功率与覆盖率计算。区间 PDF 使用摘要，CSV 按会话读取，避免导出时一次载入全部历史曲线。屏幕绘图保留断点与区间极值后减少绘图点，磁盘、统计、PDF 和 CSV 均不使用这种绘图抽点。
